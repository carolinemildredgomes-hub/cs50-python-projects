# Einstein

## Description
This program calculates the amount of energy equivalent to a given mass using Einstein's famous equation:

E = mc²

where:
- E = energy
- m = mass
- c = speed of light (300000000 meters per second)

## How It Works
1. The program asks the user to input a mass in kilograms.
2. It calculates the energy using the formula E = m × c².
3. The energy value is printed as output.

## Example

Input:
1

Output:
90000000000000000

## File
- `einstein.py` – Python program that calculates energy from mass.
