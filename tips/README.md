# Tip Calculator

## Description
This program calculates the tip amount based on the cost of a meal and the tip percentage entered by the user.

## How It Works
1. The program asks the user how much the meal cost.
2. It asks the user what percentage they would like to tip.
3. The program converts the inputs into numerical values.
4. It calculates the tip and displays the result.

## Example

Input:
How much was the meal? $50.00  
What percentage would you like to tip? 15%

Output:
7.5

## File
- `tip.py` – Python program that calculates the tip amount.
