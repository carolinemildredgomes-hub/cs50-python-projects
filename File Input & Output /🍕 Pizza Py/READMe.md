# 🍕 Pizza Py

A CS50-style Python project designed to strengthen **CSV reading, third-party library usage, and data presentation**.

This project reads a pizza menu from a CSV file and displays it as a **beautiful ASCII grid table** using the `tabulate` package.

---

## 📌 Project Objective

Convert CSV data like:

```csv
Regular Pizza,Small,Large
Cheese,$13.50,$18.95
1 topping,$14.75,$20.95
```

Into a formatted table:

```text
+-----------------+---------+---------+
| Regular Pizza   | Small   | Large   |
+=================+=========+=========+
| Cheese          | $13.50  | $18.95  |
+-----------------+---------+---------+
```
