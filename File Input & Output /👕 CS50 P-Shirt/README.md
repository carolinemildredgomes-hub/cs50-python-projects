# 👕 CS50 P-Shirt

A CS50-style Python project designed to strengthen **image processing, file validation, and Pillow library usage**.

This project overlays a transparent CS50 shirt image on top of an input image after resizing and cropping it to fit perfectly.

---

## 📌 Project Objective

Take an input image:

```text
before1.jpg
```

Resize it to match the shirt dimensions and overlay:

```text
shirt.png
```

Then save the final output image:

```text
after1.jpg
```

This simulates a **virtual try-on image editing tool**.

---

## 🛠 Technologies Used

- Python
- Pillow (`PIL`)
- `os`
- `sys`

---

## 📦 Installation

Install Pillow:

```bash
pip install Pillow
```

## 🧠 Concepts Practiced

- image file handling
- resizing and cropping
- transparency masking
- extension validation
- saving processed images

---

## ▶️ How to Run

```bash
python shirt.py before1.jpg after1.jpg
```

---

## 📂 Features

- supports `.jpg`, `.jpeg`, `.png`
- validates input/output formats
- resizes image automatically
- overlays transparent shirt
- saves processed output
- handles missing files safely
